# sugacon-shop

Digital products sold via Payhip. This repository holds the build scripts and listing drafts only.

- `product/freelancer-tracker/` — Freelancer Income & Tax Set-Aside Tracker (.xlsx): `build.py` generates the workbook, `make_cover.py` the cover image, `LISTING.md` the draft listing.

Revenue records are kept privately (not in this public repository). No personal data, credentials or identity documents belong here.
